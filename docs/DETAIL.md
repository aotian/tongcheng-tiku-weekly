# 童澄每周课程发布助手

属于老师的「每周一次」向导：把建课、排课次、双版课件、随堂绑题、作业 v2、考试与课次任务链收进一条流程，并在真正写库之前先给一份可核对的预演清单。

## 能做什么

- **Step 1 建课 / 排课次 / 跨班复制**：新建课程与章节、往章节追加课次、复制教学计划；跨班复制任务链必须先看差异预览，套用时带回服务端给的 `expected_preview_hash`。
- **Step 2 课件双版**：学生版 HTML/资料走签名直传阿里云 OSS 后写入 `topics`；教师私有版走私有接口（≤3MB、必须是 HTML），由后端回写 `topics.resource_meta.courseware_html`。
- **Step 3 绑题 / 作业 / 考试 / 任务链**：`lesson_sidebar` 候选题检索与排序、保存草稿与发布/撤回；作业 v2 的截止、补交策略、公开或定向；考试的时长、及格分与组题；课次五个阶段的任务链。同一课次内 `(homework, homework)` 与 `(exam, after_class)` 二选一互斥，单独挂载均允许；视频仅限 `in_class / after_class` 阶段。
- **Step 4 预演与发布**：预演不写库，展示每一步的方法、接口与请求体；确认后逐项执行，失败项显示中文原因并支持单步重试，已发布项支持撤回。

## 怎么用

1. 在 DSH 侧边栏点「每周课程」，面板顶部的状态条会显示当前登录的老师与角色。
2. 点「打开完整向导」（或直接访问本机 Host 的 `/tiku-weekly`），在顶部常驻栏里登录、选班级、课程、教学计划与目标课次。
3. 按 ① → ③ 填内容，每一步点「写入草稿」。草稿只在 Host 进程内保存，不写童澄后台。
4. 到 ④ 点「检查一下（不会真的发布）」，核对清单；确认无误后点「确认发布给学生」。

也可以直接对话：「查一下我的班级」「预演本周课程发布」。Agent 工具 `tiku_weekly_*` 调用的是同一套服务方法。

## 已核实的约束

- 所有 Supabase/PostgREST 请求都走同源反代 `{teach 主机}/sb/`，不直连 `*.supabase.co`；只使用登录后的 JWT，不使用 service_role。
- 可管理范围由平台 `/api/teacher/classes` 判定，并且班级必须未过期；不满足时界面直接说明原因。
- 新建班级时 `teacher_id` 由插件强制写入当前账号。
- 教师账号缺少默认学校（`quiz_school_members.school_id`）时，后端返回 409，界面会提示管理员补齐。
- 没有自动关闭作业的定时任务：截止由 `due_date` + `late_policy` + `late_until` 动态判定。

## 还没联调确认的部分

- `topics` 与课次绑定的 `type/resource_type/resource_id` 取值范围。
- `add-lesson` 的返回结构（插件已兼容 `id` / `lesson.id` / `lesson_id` 三种字段名）。
- 作业 v2 创建响应里作业 ID 的位置（已兼容 `homework.id` 与顶层 `id`）。
- 跨班复制预览响应中哈希字段名（已依次尝试 `hash`、`preview_hash`、`expected_preview_hash`）。
- 教师私有版课件按 3MB 限制在本地拦截；服务端是否还有更严格的限制需实测。
- 「本周课次」下拉读取 `lessons` 表；若该表对外不可读，下拉会显示「课次加载失败」，需要改用课次接口。
- 页面在 DSH 内打开时继承宿主主题；脱离宿主单独访问时使用内置的浅色/深色配色。

以上任何一项与线上不一致时，`test/contract.mjs` 会先失败，而不是等到老师发布时才发现。
